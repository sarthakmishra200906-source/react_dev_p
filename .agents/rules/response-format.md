# Response Format Protocol

- **When NO instruction is provided by the user**:
  - Produce exactly a 7-line response.
  - Lines 1-3: Summary report of `project-1/backend/docs/usert.txt`.
  - Lines 4-7: Help and guide the user to complete tasks with reference to notes in the file.
- **When an instruction/prompt IS provided by the user**:
  - Produce exactly a 5-line response focused on fulfilling the user's prompt.
